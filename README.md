# Offo — AI Tools Directory

Offo is an AI tools directory for finding AI tools across writing, image, video, coding, voice, business, marketing, chatbots, design, productivity, research, and education.

- Browse featured picks and new arrivals: https://offo.dev
- Explore the full catalog: https://offo.dev/tools
- Compare pricing plans: https://offo.dev/pricing
- Submit your own AI tool: https://offo.dev/submit

Makers can paste a public website URL, review the AI-generated listing draft, and publish it. Each tool page includes a short description, tags, and a link back to the provider's site.

Offo's goal is simple: good tools, better work.
